Tech stack

Tầng Công nghệ Vai trò
Framework Astro 7 (server-rendered) Render HTML mỗi request
CMS EmDash 0.40 Admin tại /_emdash/admin, schema lưu trong DB, có MCP server cho AI
Giao diện Component .astro + CSS token Không dùng framework CSS; React chỉ có trong admin
Đa ngôn ngữ Astro i18n vi mặc định (không có prefix), en ở /en
Form / lead @emdash-cms/plugin-forms Nhận form liên hệ, lưu vào D1, xem trong admin
Runtime Cloudflare Workers Chạy toàn bộ site + CMS
Database Cloudflare D1 (SQLite) Nội dung, user, lead
File ảnh Cloudflare R2 Ảnh upload từ admin
Cron Workers cron (mỗi phút) Hẹn giờ đăng bài, dọn dữ liệu form

Luồng 1 request

Ví dụ khách mở trang chi tiết dự án bản tiếng Anh.

sequenceDiagram
    participant B as Browser
    participant MW as EmDash middleware
    participant P as Page [...lang]/projects/[slug]
    participant Q as EmDash query API
    participant DB as D1
    participant L as Base.astro
    B->>MW: GET /en/projects/website-chuoi-ca-phe
    MW->>MW: khởi tạo runtime, chạy migration (lần đầu)
    MW->>P: match route (lang=en, slug)
    P->>P: kiểm tra lang (sai thì 404)
    P->>Q: getEmDashEntry(projects, slug, locale en)
    Q->>DB: SELECT ec_projects
    DB-->>Q: dữ liệu
    Q-->>P: entry (không có thì 404)
    P->>Q: getTranslations() cho nút đổi ngôn ngữ
    P->>L: render layout (SEO, nav, footer)
    L-->>B: HTML

Roadmap

Phase 1: MVP

  • ✔ Dựng EmDash + Cloudflare
  • ✔ Song ngữ vi/en
  • ✔ Trang chủ, dự án, dịch vụ, about, liên hệ
  • ✔ Form liên hệ + hộp lead
  • ✔ Docs, plans, mockup brief
  • ✔ Làm lại giao diện theo mockup (dark-first)
  • ✔ CTA band trên mọi trang
  • ◐ Nút nổi Zalo / Gọi / Messenger (chờ số thật), footer 4 cột (chờ trang FAQ/chính sách)
  • ○ Bảng giá, dải số liệu
  • ○ Thay dự án mẫu bằng dự án thật
  • ○ Deploy Cloudflare

Phase 2: Uy tín + landing dịch vụ

  • ○ Trang chi tiết từng dịch vụ (SEO + chốt khách)
  • ○ Testimonials, trang FAQ
  • ○ Lọc dự án theo ngành, case study giàu hơn
  • ○ About + hồ sơ năng lực PDF
  • ○ Chính sách bảo hành / bảo mật
  • ○ Tên miền, email báo lead, analytics

Phase 3: Content bằng AI

  • ○ Blog (có tác giả, mục lục, FAQ)
  • ○ Nối AI vào MCP server
  • ○ AI viết nháp, người duyệt
  • ○ AI dịch vi ↔ en
  • ○ 1–2 tool nhỏ đúng ngách

Phase 4: Tăng trưởng

  • ○ Công cụ dự toán giá + form lead
  • ○ Landing page theo ngành

Chi tiết đầy đủ: docs/roadmap.md. Ý tưởng lấy từ docs/research/tanphatdigital.md.
