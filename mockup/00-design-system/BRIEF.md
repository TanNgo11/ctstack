# Design system

Apply the shared style from [../README.md](../README.md).

Draw one sheet (desktop, 1440px wide) that defines the visual language used everywhere.

## Images
- `design-system-dark.png`

## Content
- Color palette with hex codes: background, surface, surface-raised, border, text, muted text, accent gradient, success, danger.
- Type scale: display (hero), h1, h2, h3, body-lg, body, small, caption, with sizes and weights.
- Buttons: primary (gradient), secondary (outline), ghost/link; default, hover, focus, disabled states.
- Cards: service card, project card, stat/result card, default + hover.
- Form inputs: text, select, textarea; default, focus, error; label + help text.
- Pills/tags: filter pill (default, active), category tag, tech-stack chip.
- Icon style sample (line icons, 1.75 stroke): globe, cart, layout, smartphone, wrench, sparkles.
- Spacing scale and radius values.
